# RetailIQ Backend

Backend service for RetailIQ, a full-stack Inventory & Billing Management System built for retail businesses.

## Overview
This repository contains the backend APIs responsible for:

- User Authentication (JWT)
- Role-Based Access Control (Admin/Staff)
- Product Management
- Sales Invoice Management
- Purchase Invoice Management
- Inventory Tracking
- Analytics Data Processing
- Company Profile Management

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Cloudinary
- Multer

## Features

- Secure authentication and authorization
- CRUD operations for products
- Sales invoice generation and storage
- Purchase invoice management
- Stock updates based on sales and purchases
- Low stock monitoring
- User-specific data isolation
- Profile management APIs

## Deployment

Backend deployed on Render.

## Note

This repository contains only the backend service used for deployment.

The complete project including both frontend and backend is available in the main RetailIQ repository.
